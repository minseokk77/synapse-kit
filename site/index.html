AI와 개발자를 위한 3대 혁신 아키텍처

단순한 빌드 툴이 아닌 지능형 인과 오케스트레이션 엔진입니다.

🧠

인과율 스마트 스킵 (Smart Skipping)

Git 작업 트리를 분석하여 실제로 변경된 파일의 종속성만 역추적합니다. 프론트엔드 수정 시 백엔드 빌드를 0.00초 만에 스킵합니다.

⏸️

대화형 인과 핫픽스 (Live-Fix Loop)

오류 발생 시 프로세스를 죽이지 않고 일시정지(`check -i`)합니다. 에디터나 AI가 파일을 수정하고 저장하는 즉시 0.05초 만에 핫 재컴파일합니다.

⚡

멀티트랙 병렬 빌더 (Parallel Builder)

Win32 C++ DLL 빌드, SvelteKit 번들링, NSIS 인스톨러 생성 등 순차 대기하던 사전 빌드 과정을 멀티코어 동시 병렬화하여 빌드 시간을 30% 이상 단축합니다.

1분 만에 프로젝트에 도입하기

설치 없이 즉시 무설치 명령어로 프로젝트에 적용할 수 있습니다.

Step 1. 설정 파일 생성

bunx synapse-kit init

Step 2. synapse.config.ts 설정

import { defineConfig, rustChecker, svelteChecker, schemaChecker } from 'synapse-kit';

export default defineConfig({
  aiMemory: {
    enabled: true,
    smartSkipping: true,
  },
  plugins: [
    rustChecker({ workspaceDir: './src-tauri' }),
    svelteChecker({ tsconfig: './tsconfig.json' }),
    schemaChecker({ targets: [{ path: './src-tauri/tauri.conf.json' }] }),
  ],
});

Step 3. 검증 실행

# 인과 스마트 검사
bunx synapse-kit check
# 전체 전방위 강제 검사
bunx synapse-kit check --all
# AI 에이전트용 초압축 출력
bunx synapse-kit check --compact
