02 / Engine Architecture

Vesper 코어 엔지니어링 메커니즘

01 • CAUSAL GRAPH
인과율 스마트 스킵
Git 작업 트리의 변경 사항(`git status -uall`)과 각 툴체인의 트리거 패턴을 교차 분석하여, 영향받지 않은 언어 서브시스템을 0.00초 만에 완벽히 생략합니다.
02 • LIVE-FIX LOOP
대화형 인과 핫픽스 (`-i`)
컴파일 에러 발생 시 프로세스를 강제 종료하지 않고 동결(`check -i`)합니다. 파일 수정 즉시 인메모리에서 0.05초 만에 핫 재컴파일하여 파이프라인을 자동 재개합니다.
03 • MULTI-TRACK
멀티트랙 병렬 빌더
Win32 PE DLL 컴파일, Svelte UI 번들링, NSIS 설치 패키지 생성 등 순차 대기하던 사전 빌드 과정을 단일 파이프라인에서 멀티코어 동시 병렬 실행합니다.
03 / Quickstart

즉시 도입하기

// 1. Initialize configuration template
$ bunx synapse-kit init
// 2. Run causal verification
$ bunx synapse-kit check
// 3. Interactive live-fix mode (pause-on-error)
$ bunx synapse-kit check -i
// 4. Compact mode for AI agents (Claude Code, Antigravity)
$ bunx synapse-kit check --compact
